Auth method

  • No authentication. No API key, token or cookie is needed. A plain browser GET returns JSON.
  • Required header (by the assignment): User-Agent: E2EUI-Tests, set globally in playwright.config.ts.
Cloudflare WAF in front of the API. Non-browser clients (curl, Playwright's request context) get a 403 HTML block page, whatever the User-Agent is (tested with E2EUI-Tests, no UA, and a Chrome UA). A browser on the same network gets through. Getting the tests through needs a WAF rule on the owner's side (for example, allow UA E2EUI-Tests).

Endpoints

Both are the same resource (/products) with different filters, so they share one response shape.

GET/products?brand={brand}

List products by brand

ParamTypeRequired*Example
brandstringyesawara

Sample: returned 91 products, all brand: "awara". Assignment check: result.data.length > 0.

GET/products?name={name}&lang={lang}&brand={brand}

Get a product by name

* "Required" reflects how the assignment uses the endpoint. Behavior without these params was not observed.

Response shape (200)

Path to data: the assignment writes status.result.data, but the real path is result.data. status is the string "ok", next to result. 
{
  "status": "ok",                 // a string, NOT an object
  "result": {
    "total_count": 91,            // equals result.data.length in both samples
    "count_by_category": {
      "category": { "Mattress": 11, "Accessories": 28, ... },
      "group":    { "Mattress": 14, "Bundle": 10, ... },
      "construction": {}, "prices": {}, "style": {}, "rooms": {},
      "colors": {}, "material": {}, "sizes": {}
    },
    "data": [ Product, ... ]
  }
}
